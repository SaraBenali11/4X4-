Sutraty: Online Shop for Women’s Fashion
Overview

Sutraty is a modern online shopping platform dedicated to women’s clothing and accessories.
This repository contains both the backend (Flask + MySQL) and the frontend (React), structured for clean development, easy deployment, and scalability.

The backend provides a complete product management API, while the frontend delivers a responsive shopping experience.

Features
Core Features

Dynamic product catalog (names, prices, categories, sizes, colors, images)

Product status flags (new arrivals, best sellers)

Full CRUD operations for product management

Responsive UI for browsing and viewing items

RESTful API with consistent JSON responses

Backend Features

Flask REST API

MySQL relational database

Automatic table creation

Environment-based configuration

CORS support

Comprehensive testing suite

Health check endpoints

Database initialization script

Frontend Features

Built with React

API integration with backend

Modern component-based architecture

Easy setup with npm
